# REF_02: ESTRUTURAS NARRATIVAS

Biblioteca de estruturas narrativas para carrosséis. Define COMO ordenar informação para reter e converter.
Princípio: **estrutura é a ordem em que tensão é criada e resolvida.** O mesmo conteúdo em ordens diferentes produz resultados diferentes. Conteúdo com arco narrativo retém mais que informação solta (heurística consolidada — não cite números de retenção como fato).

---

## OS 8 BLOCOS NARRATIVOS

| Bloco | Função | Regras-chave |
|---|---|---|
| **HOOK** | Parar o scroll em <3s | Faz sentido isolado · promete algo específico · sempre Card 1 |
| **SETUP** | Criar identificação — leitor reconhece a situação como sua | Reconhecível em <3s · é o re-hook do Card 2 (ver REF_01) |
| **BUILD** | Acumular tensão/informação | Nunca dois cards de peso igual seguidos · alternar densidade (denso → simples → denso) |
| **INTEREST PEAK** | A informação mais valiosa/inesperada — cognitivo ("não sabia disso") | Cards 4-6 em carrosséis de 7-10 · é o que o leitor repete pra alguém |
| **CLIMAX** | Pico emocional ("isso muda tudo") — ponto sem retorno | Sempre DEPOIS da tensão · distinto de Interest Peak (cognitivo ≠ emocional) |
| **FALLING ACTION** | Assentar consequências na vida real do leitor | Em 7 cards, funde com Payoff; em 9-10, 1-2 cards próprios |
| **PAYOFF** | Entregar a promessa do hook — fechar o loop | Proporcional à tensão criada · penúltimo card |
| **CTA** | Canalizar atenção em UMA ação | Sempre o último card · depois do Payoff, nunca antes |

## AS 9 ESTRUTURAS

Formato de cada entrada: quando usar / evitar · objetivos · cards · modelo · exemplo (números sempre como placeholder) · nota estratégica.

### 1. FREYTAG ADAPTADA (pirâmide clássica)
**Usar:** storytelling, jornada de transformação, marca pessoal, história genuína. **Evitar:** público muito técnico, conteúdo puramente educacional, sem história real.
**Objetivos:** Seguir, Compartilhar (primários) · Comentar, Autoridade (secundários). **Cards:** 7-9.
**Modelo:** Hook (story lead) → Setup (contexto/personagem) → Build ×2 (problema aprofundado, virada começa) → Climax (transformação) → Falling Action (aprendizado) → Payoff (estado depois) → CTA.
**Exemplo:** "Eu estava prestes a deletar meu Instagram" → "Tinha [DADO: N] seguidores, zero vendas" → "Até perceber algo que ninguém fala" → "Testei um método diferente" → "Em [PERÍODO], [RESULTADO]" → "O mais louco: não foi sobre postar mais" → "Foi sobre retenção, não alcance" → CTA único: "Segue — toda semana mostro a estratégia por dentro."
**Nota:** vulnerabilidade genuína > drama fabricado. Climax sempre antes do payoff. UM CTA só.

### 2. PAS (Problema → Agitação → Solução)
**Usar:** venda/persuasão, dor clara com solução oferecível, público morno/quente. **Evitar:** público frio (soa manipulativo), sem solução genuína.
**Objetivos:** Vender, Autoridade (primários). **Cards:** 6-8.
**Modelo:** Hook (problema) → Problema (detalhe da dor) → Agitação ×2 (por que é pior do que parece; custo de não resolver) → Interest Peak (insight-chave) → Solução → Payoff (resultado esperado) → CTA.
**Exemplo:** "Você posta todo dia e o alcance só cai" → "Volume não funciona mais" → "Você gasta tempo em algo sem retorno" → "Enquanto a concorrência avança" → "O que funciona agora é retenção" → "O método: [MÉTODO]" → "Resultado esperado: [RESULTADO]" → "Link na bio."
**Nota:** nunca pular a agitação — ela ativa aversão à perda. Solução proporcional à agitação.

### 3. ANTES / DEPOIS / PONTE
**Usar:** transformação mensurável, antes/depois como argumento (fitness, negócios, saúde). **Evitar:** sem evidência genuína, transformação exagerada.
**Objetivos:** Autoridade, Seguir, Salvar. **Cards:** 6-8.
**Modelo:** Hook (revelação do antes/depois) → Antes (dor) → Depois (aspiração) → Ponte ×2 (mudanças-chave) → Interest Peak (detalhe inesperado) → Payoff (framework) → CTA.
**Nota:** a ponte é onde mora o valor. Timeline específica e realista. Prova real ou placeholders.

### 4. MINI-MISTÉRIO
**Usar:** maximizar retenção, informação genuinamente surpreendente. **Evitar:** resposta decepcionante, enrolação sem surpresa.
**Objetivos:** Salvar, Seguir, Compartilhar. **Cards:** 7-9.
**Modelo:** Hook (a pergunta) → Setup (por que importa) → Pista 1 → Pista 2 (contradiz a 1) → Build → Climax (resposta) → Payoff (aprendizado) → CTA ("qual era sua resposta? comenta").
**Nota:** loop mental aberto força o swipe. Resposta no card 6+, nunca antes.

### 5. LISTA COM NARRATIVA
**Usar:** nicho educativo, valor de referência, objetivo salvar. **Evitar:** itens óbvios, público frio com lista genérica.
**Objetivos:** Salvar, Autoridade, Educar. **Cards:** 7-9.
**Modelo:** Hook (promessa numérica) → Contexto (por que a lista importa) → Item 1 → Item 2 → Item 3 (cada um com micro-contexto) → Interest Peak (o item mais inesperado) → Payoff (síntese que conecta tudo) → CTA.
**Regra crítica:** o item mais surpreendente vai no penúltimo slot de valor, nunca primeiro. Ordem de impacto crescente.
**Nota:** 3-7 itens. Cada item com justificativa, não só afirmação.

### 6. FRAMEWORK / MÉTODO
**Usar:** método com nome e lógica própria, posicionar expertise replicável. **Evitar:** sem sistema real, método complexo demais para carrossel.
**Objetivos:** Autoridade, Educar, Seguir. **Cards:** 8-10.
**Modelo:** Hook (nome do framework + promessa) → O que é (1 frase) → Por que funciona → Passo 1 → Passo 2 → Passo 3 → Interest Peak (o detalhe que ninguém fala) → Exemplo real ([CASO REAL] ou exemplo genérico declarado) → Payoff (resultado de quem aplica) → CTA.
**Regra crítica:** nome memorável e apropriável ("Método SAVE", "Framework 3C") > "como fazer X em 5 passos".

### 7. MITO vs. VERDADE
**Usar:** reframe, desinformação prevalente no nicho, insights genuinamente diferentes. **Evitar:** verdade óbvia ou indefensável.
**Objetivos:** Autoridade, Comentar, Compartilhar. **Cards:** 7-9.
**Modelo:** Hook (a crença que será destruída) → Mito 1 + Verdade 1 → Mito 2 + Verdade 2 → Mito 3 + Verdade 3 → Interest Peak (o mito mais chocante) → Aprofundamento (por que esses mitos existem) → Payoff (nova perspectiva) → CTA ("qual desses você acreditava?").
**Nota:** cada verdade precisa ser defensável. Altamente compartilhável.

### 8. ESTUDO DE CASO
**Usar:** resultado genuíno de cliente/projeto (com permissão), prova social. **Evitar:** caso fictício, outlier não-replicável, dados sem permissão.
**Objetivos:** Autoridade, Vender, Seguir. **Cards:** 8-10.
**Modelo:** Hook (resultado final) → Quem (contexto humano) → Situação inicial (números) → Problema real (diagnóstico) → Solução aplicada → Interest Peak (o elemento surpreendente) → Resultado (números) → O que você pode replicar → Payoff (aprendizado universal) → CTA.
**Nota:** números específicos > redondos — desde que reais. Todos os dados vêm do usuário ou viram placeholder.

### 9. ESPIRAL DE APROFUNDAMENTO
**Usar:** expertise profunda, autoridade máxima, público que quer aprender de verdade. **Evitar:** público que quer dica rápida, aprofundamento inconsistente.
**Objetivos:** Autoridade, Seguir, Salvar. **Cards:** 8-10.
**Modelo:** Hook (tema familiar — "você acha que sabe") → Nível 1 (o óbvio) → Nível 2 (poucos sabem) → Nível 3 (quase ninguém) → Nível 4 (especialistas) → Interest Peak (insiders) → Climax (o insight mais raro) → Payoff (como aplicar) → CTA.
**Regra crítica:** cada nível genuinamente mais profundo. Afirmações técnicas sobre algoritmo/plataforma só com fonte real ou formuladas como observação ("na prática, o que vejo é...") — nunca como fato numérico inventado.

## ERROS COMUNS

1. **Climax precoce** — resposta no slide 3 mata o deslize.
2. **Interest Peak confundido com Climax** — um é saber, outro é sentir.
3. **Build monótono** — slides de peso igual em sequência.
4. **Payoff menor que a promessa** — perde confiança.
5. **CTA antes do Payoff** — quebra a satisfação narrativa.
6. **Dois CTAs** — o exemplo clássico do erro: penúltimo card pede "salva" e o último pede "segue". Escolher UM.
7. **Números de exemplo tratados como fato** — todo número que não veio do usuário é placeholder.
