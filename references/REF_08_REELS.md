# REF_08: REELS — ROTEIRO EM 3 CAMADAS (Etapas C-R e D-R)

Produz roteiro completo de Reels: **Roteiro** (fala) + **Direção Nativa** (capturada na filmagem) + **Direção Gráfica** (pós-produção). Hooks: REF_01. CTAs: REF_03 (seção Reels). Gates: REF_09.

**Pré-condições:** objetivo definido · tema confirmado · tom alinhado · automação registrada no estado · hook aprovado (Etapa B-R).

---

## FASE 2 — ROTEIRO COMPLETO (aprovação obrigatória antes das direções)

### Estruturas por formato

**Educacional (alcance + salvar):**
`[HOOK 0-3s]` hook aprovado → `[SETUP 3-8s]` contexto mínimo → `[CORPO 8-40s]` 2-4 blocos, cada um entregando algo novo (dado surpreendente → aprofundamento/contraintuição → aplicação prática ou erro comum) → `[PAYOFF 40-50s]` revelação/síntese → `[CTA 50-60s]`

**Opinião (comentários + engajamento):**
`[HOOK 0-3s]` afirmação controversa → `[POSIÇÃO 3-10s]` sem rodeios → `[ARGUMENTOS 10-40s]` 2-3 argumentos com dado/exemplo concreto; reconhecer o contraponto antes de rebater → `[FECHAMENTO 40-50s]` posição em 1 frase → `[CTA 50-60s]` pergunta binária/curta

**Storytelling (conexão + compartilhar):**
`[HOOK 0-3s]` momento de tensão/virada → `[CONTEXTO 3-10s]` quem/onde/problema → `[CONFLITO 10-35s]` o que aconteceu → `[VIRADA 35-50s]` o que mudou → `[LIÇÃO 50-55s]` insight transferível → `[CTA 55-60s]` compartilhar/comentar

**Prova de Resultado (vendas + leads):**
`[HOOK 0-3s]` resultado com número concreto (real ou [RESULTADO]) → `[ANTES 3-10s]` situação inicial → `[O QUE FEZ 10-35s]` método específico → `[RESULTADO 35-45s]` prova concreta → `[TRANSIÇÃO 45-52s]` conexão com o público → `[CTA 52-60s]` próximo passo direto

### Regras de roteiro
- 150-250 palavras totais · cada bloco entrega algo novo, sem repetição
- Linguagem falada, para 1 pessoa (não "pessoal", não "galera" a menos que seja a voz do perfil)
- Dados reais ou placeholders marcados — nunca inventar
- 1 CTA, alinhado ao objetivo + automação
- Apresentar com blocos, timing estimado e contagem de palavras. Aguardar aprovação.

## FASE 3 — DIREÇÃO NATIVA (Camada 1)

Elemento capturado durante a filmagem que cria loop cognitivo nos primeiros 1-3s. Deve parecer acidente/coincidência — nunca encenado.

| Categoria | Exemplos | Efeito |
|---|---|---|
| Gesto incomum | segurar objeto de forma estranha, apontar para fora do frame | interrupção de padrão |
| Objeto quase caindo | xícara na beira da mesa, celular equilibrado | tensão micro, atenção involuntária |
| Local inusitado | dentro do carro, corredor vazio, escada | contexto que intriga |
| Expressão fora do padrão | sobrancelha erguida antes de falar, sorriso reprimido | sinaliza que algo vem |
| Ambiente inesperado | mesa bagunçada, papel colado na parede | autentica o momento |
| Ação interrompida | abrir algo e parar, escrever e pausar | expectativa de continuação |

**Entrega:**
```
DIREÇÃO NATIVA:
Elemento: [nome]
Instrução para filmagem: [exatamente o que o criador faz]
Timing: primeiros [X] segundos
Por que funciona: [efeito psicológico, 1 frase]
```
Regra: o elemento nativo não compete com a fala — retém nos primeiros segundos; o roteiro conduz o resto.

---

## FASE 4 — DIREÇÃO GRÁFICA (Camada 2)

Máximo 2-3 elementos por vídeo de 60s. Timing preciso: o elemento entra quando o dado/frase é dito. Paleta coerente com a identidade coletada. Para iniciantes: priorizar text overlay e caption visual.

| Elemento | Quando | Especificar |
|---|---|---|
| Text overlay | reforçar palavra-chave/dado | palavra + posição + estilo |
| Side-by-side | comparação antes/depois | layout + sincronização com a fala |
| Data overlay | número em destaque | número grande + entra quando citado |
| Caption visual | legendas estilizadas | palavras destacadas em cor |
| SFX | virada, dado impactante | tipo (woosh, ding, bass) + timing |
| Zoom/cut rápido | ritmo, retenção | frame + velocidade |
| Subtítulo destacado | fala rápida/técnica | bold, cor contrastante |

**Entrega:**
```
DIREÇÃO GRÁFICA:
Elemento 1: [tipo]
  → Timing: [00s-00s | "quando disser [frase]"]
  → Instrução: [o que, onde, como]
  → Estilo: [cor, fonte, tamanho relativo]
[Elemento 2, 3 se houver]
```

## ERROS A EVITAR

1. "Hoje eu vou te mostrar..." — o hook É a informação, não a promessa dela.
2. Dado sem fonte ou inventado — placeholder sempre.
3. CTA de automação sem gate confirmado.
4. Direção gráfica genérica ("adicione texto") — especificar qual, onde, quando, como.
5. Elemento nativo encenado demais.
6. Mais de 1 CTA.
7. Avançar fase sem aprovação explícita.
8. Mais de 3 elementos gráficos (poluição).
